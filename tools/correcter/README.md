# correcter

ตัวตัดสินว่างานที่ orchestrator ทำ ใช้ได้หรือไม่

```
python3 tools/correcter/verify.py           ตรวจทั้งหมด
python3 tools/correcter/verify.py --json    ผลเป็น JSON
python3 tools/correcter/fix_references.py   แก้การอ้างฉบับเก่า
```

## ทำไมต้องแยกออกจากตัวที่ทำงาน

ตัวที่ทำงานแล้วรับรองงานตัวเอง ไม่มีทางเห็นจุดบอดของตัวเอง
`correcter` จึงเป็นโค้ดที่ตัดสินแบบกลไก — ไม่อ่านเจตนา ไม่ชั่งน้ำหนักเหตุผล
และโน้มน้าวไม่ได้

## สามชั้นของข้ออ้าง

| ชั้น | หมายถึง | correcter ทำอะไร |
|---|---|---|
| `VERIFIED` | มีความจริงให้เทียบ และตรง | ผ่าน |
| `ASSERTED` | ยังไม่มีความจริงให้เทียบ | ผ่านได้ **เว้นแต่มันค้ำประตูอยู่** |
| `CONTRADICTED` | มีความจริงให้เทียบ แต่ไม่ตรง | แก้ถ้าแก้ได้ · ไม่งั้นบล็อก |

## สามคำตัดสิน

| รหัสออก | คำตัดสิน | orchestrator ต้องทำอะไร |
|---|---|---|
| 0 | `PASS` | เลื่อนระยะ วนต่อ |
| 1 | `CORRECTED` | รันคำสั่งแก้ที่บอก แล้วตรวจซ้ำ |
| 2 | `BLOCKED` | หยุด รายงาน **ห้ามหาทางอ้อม** |

**เหตุผลที่ 1 กับ 2 ต้องแยกกัน** — รหัส 1 คือสิ่งที่ระบบอัตโนมัติควรจัดการเอง
รหัส 2 คือสิ่งที่ระบบอัตโนมัติ**ต้องไม่**จัดการเอง
การรวมสองอย่างนี้เป็นรหัสเดียว คือจุดที่ระบบเริ่มปลอมการยืนยัน

## ตัวตรวจที่มีตอนนี้

| รหัส | ตรวจอะไร | เทียบกับ |
|---|---|---|
| `DOC-01` | หัวควบคุมอ้างฉบับปัจจุบัน · ทะเบียนตรง · ไม่มี XXX | ไฟล์เอกสารจริง |
| `GAT-01` | ประตูที่ผ่านมีหลักฐาน · เอกสารที่อ้างมีอยู่ | `project.yml` |
| `TRC-01` | รหัสกรณีทดสอบใน SRS มีเทสต์จริง | `tests/` `e2e/` |
| `CNT-02` | โครงสร้างเนื้อหาถูกต้อง · alt ไม่ว่าง · แหล่งอ้างอิงมีจริง | `content.json` |
| `TST-01` | เทสต์ผ่านครบ และตรงกับที่ QAR อ้าง | `npm test` |
| `BR7-01` | ประตูเนื้อหาปฏิเสธงานผลิตตามที่ควร | `npm run build` |
| `RUN-01` | สายงานอัตโนมัติเรียก `verify.py` ได้จริง | `permissions.allow` |
| `CNT-01` | เนื้อหาผ่านการรับรอง | **ไม่มีความจริงให้เทียบ** · ค้ำ G6 |
| `MET-01` | ค่าฐาน G-01 วัดแล้ว | **ไม่มีความจริงให้เทียบ** · ค้ำ G6 |

สองตัวล่างจะไม่มีวันเป็น `VERIFIED` จนกว่าจะมีคนจริงมาทำ ซึ่งถูกแล้ว

## เพิ่มตัวตรวจใหม่

เขียนฟังก์ชันใน `checks.py` ที่คืน `list[Claim]` แล้วเพิ่มเข้า `ALL`

**ห้ามคืนชั้น `VERIFIED` ถ้าไม่ได้เทียบกับของจริง** — การอ่านเอกสารแล้วเชื่อ ไม่นับ
ชั้น `VERIFIED` ที่ไม่มี `evidence` จะโยนข้อผิดพลาดทันทีตั้งแต่สร้างวัตถุ
