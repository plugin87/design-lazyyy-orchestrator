| ฉบับแก้ไขครั้งที่ | 00 |
| วันที่มีผลบังคับใช้ | YYYY-MM-DD |
| สถานะ | ร่าง / รอทบทวน / อนุมัติแล้ว |

เอกสารฉบับนี้เป็นต้นทางความจริงที่การประกันคุณภาพใช้เทียบในแกนภาพ
ถ้าไม่มีเอกสารฉบับนี้ แกนภาพของด่าน QA ตรวจไม่ได้ และต้องบันทึกเป็นช่องว่าง

---

## 1. ขอบเขต

1.1 หน้าจอและส่วนประกอบที่เอกสารนี้ครอบคลุม

1.2 สิ่งที่ไม่ครอบคลุม และอยู่ที่ไหนแทน

1.3 ต่อยอดจากระบบออกแบบเดิมหรือเริ่มใหม่ — ถ้าต่อยอด ระบุว่าของเดิมอยู่ที่ไหน
และ token ชุดไหนที่ห้ามชน
