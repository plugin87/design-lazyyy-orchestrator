## 2. คำตัดสิน

| รายการ | ผล |
|---|---|
| คำตัดสิน | REQUEST CHANGES / APPROVE WITH CHANGES / APPROVE |
| BLOCKER | 0 |
| MAJOR | 0 |
| MINOR | 0 |
| NIT | 0 |

คำตัดสินคำนวณจากจำนวนข้อค้นพบ ไม่ใช่การเลือก — มี BLOCKER แม้ข้อเดียว ⇒ REQUEST CHANGES
· ไม่มี BLOCKER แต่มี MAJOR ⇒ APPROVE WITH CHANGES · ไม่เกิน MINOR ⇒ APPROVE

## 4. สิ่งที่ทำได้ดี

## 5. ช่องว่างของการทบทวนครั้งนี้

สิ่งที่ทบทวนไม่ได้และเหตุผล — ไม่มีเจตนาให้เทียบ ไม่มีสภาพแวดล้อมให้รัน
หรือส่วนที่อยู่นอกขอบเขต
