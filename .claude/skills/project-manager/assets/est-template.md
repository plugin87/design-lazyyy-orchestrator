## 1. ขอบเขตและฐานของการประมาณ

1.1 ประมาณจากอะไร — ข้อกำหนดฉบับไหน ฉบับแก้ไขที่เท่าไหร่

1.2 **ประมาณ ณ ช่วงไหนของโครงการ** — ก่อนออกแบบ ค่าประมาณจะคลาดเคลื่อนสูง
และต้องประมาณใหม่หลังออกแบบเสร็จ ตัวเลขในเอกสารนี้ไม่ใช่คำสัญญา

1.3 อะไรไม่รวมอยู่ในตัวเลขนี้

## 2. วิธีที่ใช้

| วิธี | ใช้กับงานแบบไหน |
|---|---|
| เทียบกับงานอ้างอิง | มีงานลักษณะเดียวกันที่เคยทำจริงและรู้เวลาจริง |
| สามจุด (PERT) | งานเดี่ยวที่ไม่แน่นอน — `(ดี + 4×น่าจะ + แย่) / 6` |
| แตกย่อยแล้วรวม | งานใหญ่ที่แตกเป็นชิ้นที่ประมาณได้ |

ระบุว่าใช้วิธีไหนกับข้อไหน และตัวเลขไหนเป็นการเดา
